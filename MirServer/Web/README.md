# МИР Engineering Web MVP

Первый веб-прототип коммерческой платформы МИР: заказчик, руководитель проекта и команда инженеров работают внутри одного живого проекта.

## Уже реализовано

- клиентское рабочее пространство проекта;
- 3D-вьюпорт-прототип;
- пространственные стикеры пожеланий;
- этапы проекта;
- список инженерных задач;
- предложение свободной задачи инженеру;
- простая модель команды и финансового потока;
- адаптивная вёрстка.

## Следующий слой

1. авторизация и роли `client / manager / engineer`;
2. создание заказа с загрузкой файлов;
3. серверная модель `Project / Stage / Task / Comment / Sticker / File`;
4. реальное хранение 3D-файлов;
5. привязка стикеров к координатам модели;
6. WebSocket-события проекта;
7. личный кабинет инженера и история выплат;
8. подключение MirServer API и МИР 4D Viewer.

Прототип намеренно не зависит от внешних UI-фреймворков: это чистые HTML/CSS/JS, чтобы интерфейс можно было быстро встроить в серверную часть МИР.
