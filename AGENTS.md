# 17. CVDisplayLink

CVDisplayLink работает на отдельном потоке.

Callback CVDisplayLink НЕ является MainActor.

Запрещено напрямую обращаться из callback к MainActor-isolated объектам.

Неправильно:

```swift
view.renderFrame()
```

если метод требует MainActor.

Необходимо использовать:

```text
CVDisplayLink
      │
      ▼
thread-safe signal
      │
      ▼
render execution
```

или поток рендера MirEngine, если он предусмотрен архитектурой.

---

# 18. Swift 6 Concurrency

Проект должен быть совместим со Swift 6.

Особое внимание:

* `@MainActor`;
* `Sendable`;
