MirUI/Renderers/SwiftUI/README_BUILD.md

╔══════════════════════════════════════════════════════╗
║  ИНСТРУКЦИЯ: Как собрать и запустить MirUI на macOS  ║
╚══════════════════════════════════════════════════════╝

✅ Всё необходимое уже написано. Осталось правильно
   сложить файлы в Xcode-проект и нажать Run.

═══════════════════════════════════════════════════════
ШАГ 1. Создайте проект в Xcode
═══════════════════════════════════════════════════════

1. Откройте Xcode → File → New → Project...
2. Выберите macOS → App
3. Название: MirUIApp
4. Interface: SwiftUI
5. Language: Swift
6. Сохраните в удобное место.

═══════════════════════════════════════════════════════
ШАГ 2. Добавьте ВСЕ исходники MirUI в проект
═══════════════════════════════════════════════════════

1. В Finder откройте папку с вашим проектом MirUI.
2. Перетащите в Xcode (в левую панель, под MirUIApp) 
   следующие папки ЦЕЛИКОМ:

   📁 Core
   📁 Foundation
   📁 Widgets
   📁 Workspace
   📁 Designer
   📁 Schema
   📁 Renderers
   📄 MirUI.hpp

3. В появившемся диалоге ВАЖНО поставить галочки:
   ✅ Copy items if needed
   ✅ Create groups
   ✅ Добавить в target "MirUIApp"

4. После добавления убедитесь, что в Target → Build Phases 
   → Compile Sources есть файлы:
   - Widget.cpp
   - WidgetTree.cpp
   - SwiftUIRenderer.mm
   - MirUICppBridge.mm
   (если нет — перетащите их туда вручную)

═══════════════════════════════════════════════════════
ШАГ 3. Настройте Bridging Header
═══════════════════════════════════════════════════════

1. Кликните на проект (синяя иконка) → MirUIApp target
2. Вкладка Build Settings
3. В строке поиска введите "Bridging"
4. Найдите Objective-C Bridging Header
5. Укажите путь (относительно папки проекта):
   MirUI/Renderers/SwiftUI/MirUI-Bridging-Header.h

═══════════════════════════════════════════════════════
ШАГ 4. Включите C++23
═══════════════════════════════════════════════════════

1. В Build Settings найдите C++ Language Dialect
2. Выберите C++23 (или GNUC++23)
3. Убедитесь, что C++ Standard Library = libc++

═══════════════════════════════════════════════════════
ШАГ 5. Замените ContentView.swift на наш код
═══════════════════════════════════════════════════════

1. Удалите сгенерированный ContentView.swift (или закомментируйте)
2. В файле MirUIApp.swift (который сгенерировал Xcode)
   замените ВСЁ содержимое на код из нашего файла
   MirUIApp.swift (последняя версия с C-функциями).

   ИЛИ просто откройте наш MirUIApp.swift и скопируйте
   его содержимое в сгенерированный файл.

═══════════════════════════════════════════════════════
ШАГ 6. Убедитесь, что все Swift-файлы в проекте
═══════════════════════════════════════════════════════

В левой панели должны быть видны:
   📄 MirUIApp.swift          (главное приложение)
   📄 MirUISwiftBridge.swift  (Swift-мост для ViewNodes)
   📄 MirUI-Bridging-Header.h (bridging header)

   И в Compile Sources:
   📄 SwiftUIRenderer.mm      (C++ часть рендерера)
   📄 MirUICppBridge.mm       (Objective-C++ мост)

═══════════════════════════════════════════════════════
ШАГ 7. Запустите!
═══════════════════════════════════════════════════════

Нажмите ▶ Run (или ⌘R).

Через несколько секунд должно появиться окно с:
   • Серой панелью "MirUI Designer"
   • Кнопкой "Нажми меня!" и ещё несколькими элементами
   • При нажатии на кнопку в консоли появится сообщение
     о выполнении команды.

═══════════════════════════════════════════════════════
ЧТО ДЕЛАТЬ, ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
═══════════════════════════════════════════════════════

❌ Ошибка "Bridging header not found"
   → Проверьте путь в Build Settings (шаг 3).
   → Путь должен быть относительно КОРНЯ ПРОЕКТА,
     а не относительно файла проекта.

❌ Ошибка линковки "Undefined symbol: MirUI_Init"
   → Убедитесь, что MirUICppBridge.mm добавлен
     в Compile Sources (шаг 2).

❌ Ошибка "Use of undeclared identifier 'MirUI_...'"
   → Проверьте, что в bridging header (MirUI-Bridging-Header.h)
     объявлены нужные функции.
   → Убедитесь, что bridging header указан в настройках.

❌ Ошибка компиляции C++ "no member named '...'"
   → Проверьте C++ Standard = C++23 (шаг 4).
   → Убедитесь, что все .hpp файлы добавлены в проект
     (Xcode должен их видеть, даже если они не компилируются).

═══════════════════════════════════════════════════════
ЧТО ДАЛЬШЕ?
═══════════════════════════════════════════════════════

🎉 Поздравляю! Если окно открылось и показывает кнопки,
   значит архитектура MirUI работает полностью:

   C++ DesignerApplication
        ↓
   C++ WidgetTree + LayoutEngine
        ↓
   SwiftUIRenderer (C++ → ViewNode)
        ↓
   MirUI_SwiftUI_UpdateViewNodes (C-мост)
        ↓
   MirUISwiftBridge.swift (ViewNode → SwiftUI View)
        ↓
   MirUIRootView (отображение на экране)

Теперь можно:
   • Добавить больше типов виджетов в SwiftUIRenderer
   • Реализовать перетаскивание и изменение размера
   • Подключить настоящий DesignerCanvas
   • Сделать WinUI-адаптер по тому же шаблону
